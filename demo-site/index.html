Better X saves posts from X into a private library in your browser and downloads their photos and videos at full quality. It can also clean up the site itself: Clean turns on 12 switches that hide ads, Grok, Premium upsells and suggested accounts, and turning it off puts everything back.

        03 · How it works

        Four parts, each one in its own module.

        1. 1

          Save

          A shared runtime watches X’s timeline as it loads and adds the Save button to each post’s action row. One click reads the post: text, author, date from the post id, photos, videos, the quoted post, the reply and the link card.

          src/x/selectors.ts
        2. 2

          Keep

          Bookmarks go into IndexedDB in single transactions, so two tabs saving at once can’t overwrite notes, tags or download history. The side panel searches, filters, tags and exports them.

          src/storage/repository.ts
        3. 3

          Customize

          Each setting is a few CSS rules. Every rule that’s on goes into one <style> element, rewritten whenever a switch or slider changes. Nothing is removed from X’s page, so turning a setting off is instant.

          src/features/host.ts
        4. 4

          Theme

          Three colors become 17 tokens with contrast guarantees. One table maps them onto X’s surfaces, checked against X’s own stylesheet, so a change on X’s side leaves a patch of black, never unreadable text.

          src/themes/derive.ts

        Also in the extension

        Media downloads
        Original-resolution photos, GIFs as the MP4 X hosts, and videos where X publishes an MP4. Saved to Downloads/Better-X.
        Account insights
        Optional badges for where X says an account is based and how it connects, from X’s own “About this account” data.
        Smart filtering
        Collapse, hide or highlight posts from accounts X places in countries you choose. Only your own view changes.
        Plugins
        SpotifyControls puts a player above your account switcher, using your own Spotify app.
        Open it your way
        Side panel, an overlay drawn inside the X tab, a compact popup, or a floating window. Alt+Shift+B toggles it.
        Backups
        JSON export and validated import for your library and your settings, including Saved for X backups.

        What it never touches

        Better X changes what you see, not your account.

        • Your X password
        • Stored cookies or tokens
        • X’s API
        • Other websites
        • Analytics
        • Files it downloaded
        • Photos and videos’ colors
        • Its own Save button

        04 · Privacy

        No account. No server. No analytics.

        Your library, settings and download history stay in your browser. Exports hold metadata only, never media or file paths. Better X doesn’t store or send any cookie, token or header.

        storage
        Settings, and a small marker that keeps open tabs and the library in sync.
        sidePanel, activeTab
        Open the library from the toolbar icon, and tell an X tab from another site at the moment you click.
        downloads
        Save the media you choose. Other downloads are never read.
        x.com, twitter.com
        Add the Save button and read only the post you save.
        X’s media hosts
        Check a file and find a public post’s video, only when you click Download.
        identity, Spotify hosts
        Only for the Spotify plugin, while it’s on and connected.

        05 · Install

        Build it, then load it into Chrome.

        Better X isn’t on the Chrome Web Store yet. You need Node.js 20.19+ and Chrome 116+.

        1. 1
          Build it
          git clone https://github.com/ztxv/better-x.git
cd better-x
npm ci
npm run build
        2. 2
          Turn on Developer mode

          Open chrome://extensions and switch on Developer mode in the top-right corner.

        3. 3
          Load unpacked

          Choose .output/chrome-mv3, pin Better X, and refresh any open X tab.
