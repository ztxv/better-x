# Synthetic backup fixtures

Small, made-up backups in every format Better X imports: `saved-for-x` versions 1, 2, and 3 (the
extension Better X grew out of) and `better-x` version 1. They share the same two posts so each
version's additions are easy to compare:

- version 1: bookmarks and a collection, with tags, a note, and author details;
- version 2: adds post context (a photo, a quoted post with a GIF, a link card, a reply);
- version 3 and `better-x` 1: add media source URLs and completed download history (a photo and a
  quoted GIF).

All handles, IDs, and media IDs are invented. Never replace these with a real export.
